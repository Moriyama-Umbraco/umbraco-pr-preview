# Umbraco PR Preview

Adds an **Umbraco** tab to pull requests. Changed uSync (`uSync/v*/DataTypes`, `ContentTypes`, `MediaTypes`, `MemberTypes`) and Umbraco Deploy (`umbraco/Deploy/Revision/*.uda`) schema files are rendered with the real Umbraco backoffice property editors — target branch on the left, pull request on the right — with added, removed and changed tabs, groups, properties and configuration highlighted.

Supports Umbraco 17 and 18.
