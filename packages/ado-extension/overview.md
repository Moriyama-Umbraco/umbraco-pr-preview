# Umbraco PR Preview

Adds an **Umbraco** tab to pull requests. Changed uSync (`uSync/v*/DataTypes`, `ContentTypes`, `MediaTypes`, `MemberTypes`) and Umbraco Deploy (`umbraco/Deploy/Revision/*.uda`) schema files are rendered with the real Umbraco backoffice property editors, with the target branch and the pull request shown together and added, removed and changed tabs, groups, properties and configuration highlighted.

Supports Umbraco 17 and 18.

Report issues or suggest features on [GitHub](https://github.com/Moriyama-Umbraco/umbraco-pr-preview/issues).
